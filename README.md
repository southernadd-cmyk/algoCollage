# ALGO/COLLAGE

**Collect. Cut. Compose.**

A new browser collage project using the ALGO/ART composition engine.

Build a pool of images from free image searches and your own uploads. One seeded ALGO/ART output cuts the images into fragments; another arranges those fragments into a new collage. The pool remains available as cuts and layouts change.

The first prototype is being developed on the `feat/initial-collage-studio` branch for review before merging.
